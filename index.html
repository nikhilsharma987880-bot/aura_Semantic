Quick Syntax Overview

AURA operates on conceptual resonance and semantic graphs instead of binary data manipulation.

# Define ontological nodes and resonance weights
INJECT "Gyan (Knowledge)" -> "Bodh (Understanding)" (0.95)
INJECT "Bodh (Understanding)" -> "Satya (Truth)" (0.92)

# Propagate conceptual waves
PROPAGATE "Gyan (Knowledge)" DEPTH 3

# Conditional autonomous triggers
IF "Bodh (Understanding)" {
    INJECT "Satya (Truth)" -> "Swayam-Srishti (Self-Creation)" (0.97)
}
